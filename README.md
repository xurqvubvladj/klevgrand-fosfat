## Overview

Fosfat manipulates the phase relationships between stereo channels to widen, narrow, or reimage the stereo field without frequency coloration, producing natural-sounding width changes on buses and masters.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Klevgrand Fosfat** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Phase Scrambler** | Manipulate inter-channel phase coherence for width adjustment |
| **Mono Compatibility** | Real-time mono-fold check meters phase cancellation risk |
| **Mid/Side Mode** | Process mid and side independently for surgical stereo shaping |
| **Correlation Meter** | Phase correlation display with safety threshold indicators |
